# Tubio
AI-powered modular pipe-inspection robot featuring ESP32, cardan shaft, YOLOv11 defect framing, and wireless FPV streaming.

best.pt is the trained YOLOv11 model weights file used for detecting pipeline defects, newcode.py serves as the main Python script for computer vision processing, and COde_esp_tubio3.ino contains the core C++ firmware for the ESP32 microcontroller to handle wireless Bluetooth control, PWM motor driving, and traction/cleaning mechanics.
